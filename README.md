# Casabella Towns — Pre-Launch Website

Static, GitHub Pages-ready pre-launch site for Casabella Towns.

## Preview locally
Open `index.html` in a browser, or run any simple static web server.

## GitHub Pages
1. Create a new repository (for example `casabella-towns-preview`).
2. Upload the contents of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Deploy from the `main` branch / root folder.

## Custom domain later
The canonical URL is already set to `https://www.casabellatowns.ca/`, but do not point the production domain until you are ready. GitHub Pages can be used on its default URL during review.

## Registration form
The current form is intentionally preview-only and does **not** transmit or store data. Once the Google Form is created, replace the submit handler in `assets/js/main.js` with the Google Form endpoint / integration.

## Content guardrails
- Do not publish the exact municipal address before land closing / authorization.
- Location copy should remain at **Oak Ridges, Richmond Hill / Yonge St & King Rd Area**.
- AI / conceptual renderings must retain the artist-concept disclaimer.
- Pricing, dimensions, features and specifications remain preliminary and subject to change.

## SEO assets
- `title`, meta description, canonical, Open Graph and Twitter metadata are included.
- `robots.txt` and `sitemap.xml` are included.
- Image filenames are SEO-friendly and use descriptive alt text.
- Replace the social preview image if the brand direction changes.
